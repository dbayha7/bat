# BAT: Ballpark Attendance Tracker

A web app you install from Safari. It opens full screen from the home screen, works without a signal, and updates itself.

## 1. Put it online (free, about 5 minutes)

1. On github.com, create a new **public** repository, for example `bat`.
2. Unzip `bat-app.zip`. On the new repo's page, choose **uploading an existing file**, drag in everything inside the `bat-app` folder, and commit.
3. Open **Settings > Pages**. Under Build and deployment, set Source to **Deploy from a branch**, Branch to **main**, folder **/ (root)**, and Save.
4. After a minute or two it's live at `https://YOUR-USERNAME.github.io/bat/`.

Any static host with HTTPS works the same way.

## 2. Install it

- **iPhone or iPad:** open the link in Safari, tap **Share**, then **Add to Home Screen**.
- **Android:** open it in Chrome and tap **Install**.

To share it, send the link. Everyone who installs it gets their own log.

## Updating

Upload the new files over the old ones. The app notices the next time it opens and shows an **Update** button.

## Your data

Your log is saved on the device, inside the installed app. That copy is separate from anything you did in a Safari tab, so install first, then log.

- **Backup > Save file** exports it. **Open file** restores it.
- Coming from the single-file version: there, Backup > Copy. Here, Backup, paste, Restore from text.

## Offline

The app opens with no signal. Box scores and pitchers you've already opened stay available, and the header shows when the scores were last updated.
